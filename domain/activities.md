## Aktivitets­spesifikke kledningskrav

### Rusling / Casual gåtur
**MET**: 3.0–4.0 | **Offset**: +3–4°C

Særtrekk:
- Lav svette-produksjon — trenger mer isolasjon enn løper ved samme temp
- Stil kan vektlegges (urbant innslag)
- Vindeksponering viktig — stillesittende mellomrom (kaffepause etc.)
- Varighet ofte kortere (15–60 min)

Kledningsprioritering: Isolasjon > pustbarhet > sportslig passform

### Løping
**MET**: 6–12 | **Offset**: +5–10°C

Særtrekk:
- Høy svetteproduksjon — **aldri bomull**, alltid fukt-transporterende
- Overoppheting-risiko selv ved lave temperaturer (se 10°C-regelen)
- Kjøling etter stopp er en fare (vind + svette = hypotermi)
- Smalere klær for aerodynamikk

**10°C-regelen for løping**: Kle deg som om det er 10°C varmere enn lufttemperaturen
(Justeres til ca. +7°C for moderat tempo, +10°C for høy intensitet)

Grenseverdier:
| Lufttemp | Anbefaling |
|---|---|
| > 20°C | Shorts + t-skjorte (lett syntetisk) |
| 15–20°C | Shorts + langermet |
| 10–15°C | Shorts/tights + langermet + lett jakke |
| 5–10°C | Tights + termolange­erm + lett løpejakke |
| 0–5°C | Tights + termo-base + mellomlag + vindjakke + hansker + lue |
| −5 til 0°C | Tykke tights + tung termo + midtre lag + vindtett + isolerte hansker |
| < −5°C | Vurder interiørtrening eller sterkt redusert eksponering |

### Sykling
**MET**: 6–12 | **Offset**: +5–9°C

Særtrekk:
- Sterk vindfaktor — sykler inn i vinden (effektiv vindavkjøling 2–3× normalt)
- Knær og lår spesielt utsatt under 15°C
- Regneklær kritisk — fuktig kald = hypotermi-risiko
- Aerodynamisk passform viktig

Grenseverdier:
| Lufttemp | Anbefaling |
|---|---|
| > 20°C | Sykkelshorts + trøye |
| 15–20°C | Sykkelshorts + langermet |
| 10–15°C | Lange sykkelshorts/tights + langermet + lett jakke |
| 5–10°C | Tights + termo-base + vindjakke + lette hansker + valgfri lue |
| 0–5°C | Tights + termo + isolert sykkeljakke + hansker + lue |
| < 0°C | Vintertights + tung termo + isolert jakke + votter + balaklava |

**Ekstraspesifikt for sykling**:
- Kne-varmere ved 10–15°C (knær tåler dårlig kulde under dynamisk bevegelse)
- Skoovertrekk/varmere ved < 10°C
- Regnjakke alltid ved > 40% nedbørssannsynlighet

### Fjelltur / Hiking
**MET**: 4–7 | **Offset**: +4–6°C

Særtrekk:
- Variabel intensitet (flat → bakke → pause)
- 3-lags-systemet er essensielt — kan legge av og på
- Varighet ofte lang (2–8 timer)
- Fjellvær skifter raskt — alltid ekstra lag i sekken
- Fukt-akkumulering over tid → bytt undertøy i sekken

Kritiske lagregler:
- **Alltid ekstra lag i sekken** ved < 15°C
- **Alltid regntøy** i sekken i Norge
- **Aldri bomull** i fjellet
- Vektlegg pustbarhet for aktive klatringer

Grenseverdier:
| Lufttemp | I sekken |
|---|---|
| > 15°C | Lett regnjakke |
| 5–15°C | Regnjakke + fleece-lag |
| 0–5°C | Regnjakke + fleece + ekstra termo-sett |
| < 0°C | Alt av vinter-lager + balaklava + votter |

### Langrenn (Cross-country skiing)
**MET**: 8–14 | **Offset**: +7–10°C

Særtrekk:
- Høyest varme-produksjon av vanlige utendørs­aktiviteter
- Forfra eksponert mot vind i glid-faser
- Stillstand­kulde etter trening (avkjøling dramatisk)
- Kompetanse-klistvoks-lignende presisjons-kriterier for klær

Kledningsregel: Kle deg som om det er 15°C varmere enn termometeret

Grenseverdier:
| Lufttemp | Anbefaling |
|---|---|
| > 5°C | Shorts eller løse bukser + typisk-løp-trøye |
| 0–5°C | Tynne tights + tynn vindjakke |
| −5 til 0°C | Medium tights + vindtett langrenn-trøye |
| −10 til −5°C | Tykke tights + vindtett melomlag + lue + hansker |
| < −10°C | Full vinter-langrenn-sett + balaklava + votter |

### Alpint / Snowboard
**MET**: 5–9 | **Offset**: +4–6°C

Særtrekk:
- Pauser på heis → kjøles ned
- Sitter i skiheisen → stillesittende kulde
- Ekstremvær er vanlig på alpinlanlegg
- Vann-eksponering (snø, fall) = fuktig klær

Kledningsregel: Fullt 3-lags-system ved < 0°C

### Klatring
**MET**: 5–9 | **Offset**: +4–6°C

Særtrekk:
- Stor variasjon: aktive perioder + passiv belaying (stå stille)
- Høy kravet til arm-bevegelighet
- Klippe-kontakt → handholding i kulde
- Innendørs vs. klippe­klatring = dramatisk forskjell

### Åpen-vann svømming
**Spesielt**: Fokus på vann­temperatur, ikke lufttemp

| Vanntemp | Anbefaling |
|---|---|
| > 20°C | Badedrakt |
| 15–20°C | Triathlon-drakt (2mm) |
| 10–15°C | Wetsuit (3mm) |
| 5–10°C | Wetsuit (5mm) + cap + votter |
| < 5°C | Wetsuit (7mm+) + cap + votter — krevende |

## Varighets­effekter

### Akkumulert svette og fordampnings­kjøling

| Varighet | Effekt | Kledningsjustering |
|---|---|---|
| < 30 min | Minimal akkumulering | Standard-anbefaling |
| 30–60 min | Lett svette­akkumulering | +5–10% isolasjon |
| 1–2 timer | Moderat akkumulering | +10–15% isolasjon |
| 2–4 timer | Betydelig akkumulering | +15–20% isolasjon, ekstra lag i sekken |
| > 4 timer | Sterkt akkumulert | +20–25%, aktiv lag-bytte, ekstra undertøy |

**Stopp-risiko**: Etter høy­intensiv aktivitet stopper varme-produksjonen dramatisk.
Svett­fuktede klær + vind = rask avkjøling. "Stopp-sjekk"-lag bør alltid planlegges.

### Varighet-multiplikator for CLO

```
CLO_adjusted = CLO_base × (1.0 + (varighet_min / 60) × 0.05)
```

Eksempler:
- 30 min: CLO × 1.025
- 60 min: CLO × 1.05
- 120 min: CLO × 1.10
- 240 min: CLO × 1.20

## Aktivitets-vær-interaksjon

### Farlige kombinasjoner

| Aktivitet | Vær | Fare | Tiltak |
|---|---|---|---|
| Sykling | Regn + < 10°C | Hypotermi | Isolert regnjakke, stopp ved avkjøling |
| Løping | Vind + regn | Svette-kjøling | Vindtett ytterlag |
| Fjelltur | Tåke + vind | Desorientering + kulde | Isolasjons-lag, GPS/kart |
| Langrenn | Snødrev | Ansikts-frostskade | Balaklava, solbriller |
| Klatring | Regn | Sleipe hold | Unngå klippen ved regn |
| Svømming | Kaldt + vind etterpå | Hypotermi etter svøm | Varmt antrekk klar ved kanten |

### Aktivitets-spesifikk vindavkjøling

Syklist i 30 km/t ved 10°C og 10 m/s medvind:
- Effektiv vind mot kroppen: 30 km/t (9 m/s) − 10 m/s = nesten ingen vind
- Effektiv vind mot kroppen (motvind): 30 + 36 = 66 km/h → vindavkjøling dramatisk

## Norsk friluftsliv-kultur

### Prinsippet "Det finnes ikke dårlig vær, bare dårlig klær"
Nordmenn kler seg for å være ute uansett vær. Implikasjoner for appen:
- Ikke fraråd aktivitet — anbefal riktig klær
- Vis respekt for utendørs­kulturen
- Prioriter sikkerhet, men legg til rette for friluftsliv hele året

### Sesong­aktiviteter

| Sesong | Typiske aktiviteter |
|---|---|
| Vinter (des–feb) | Langrenn, alpint, skiturer, vinterfjelltur |
| Vår (mar–mai) | Skitur (mars), fjelltur (mai), sykling |
| Sommer (jun–aug) | Fjelltur, sykling, svømming, padling |
| Høst (sep–nov) | Fjelltur, løping, sykling (sep), jakt |

### Spesielle norske hensyn
- **Marka-turer**: Korte til mellomlange turer i skogen nær byer (Oslo-marka, etc.)
- **Fjordlandskap**: Kraftig vindeksponering, rask værskifte
- **Høyfjell**: Over tregrensen → ekstremvær-ready alltid
- **Arktisk nord**: Midnattssol, polare forhold vinterstid
